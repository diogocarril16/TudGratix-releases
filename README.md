## ⬇️ Instalar

1. Abre a **[última versão](https://github.com/diogocarril16/TudGratix-releases/releases/latest)** e descarrega o `TudGratix-Setup-<versão>.exe`. O `TudGratix-Portable-<versão>.zip` não instala nada.
2. Abre o instalador. Pede administrador **uma vez**. Se o Windows disser "O Windows protegeu o seu PC": **Mais informações → Executar mesmo assim**.
3. Abre a TudGratix pelo menu Iniciar. As atualizações chegam pela própria app, com um clique.

**📱 Telemóvel:** descarrega o [`TudGratix-Android.apk`](https://github.com/diogocarril16/TudGratix-releases/releases/latest/download/TudGratix-Android.apk) no Android e abre. No iPhone usa-se pelo Safari, com o passo a passo na app do PC.

<details>
<summary><b>🔒 Verificar o ficheiro (recomendado)</b></summary>

<br>

No PowerShell, na pasta das Transferências:

```powershell
Get-FileHash .\TudGratix-Setup-<versão>.exe -Algorithm SHA256
```

O resultado tem de ser igual ao da linha desse ficheiro no `SHA256SUMS.txt` da mesma versão. Se não for, apaga o ficheiro e não o abras.

</details>

## ❓ Perguntas

<details><summary><b>É mesmo grátis?</b></summary><br>Sim. Sem anúncios, sem subscrição, sem versão "Pro", sem conta. Vai ser sempre 100% grátis.</details>
<details><summary><b>Porque é que o Windows diz que "protegeu o PC"?</b></summary><br>Os executáveis não estão assinados com um certificado (custa dinheiro todos os anos). Confere o SHA-256 e escolhe <b>Mais informações → Executar mesmo assim</b>.</details>
<details><summary><b>Porque pede administrador?</b></summary><br>As temperaturas e o FPS só se leem como administrador. Pede uma vez, na instalação; depois a app arranca sem perguntar. O painel e o overlay correm sem privilégios.</details>
<details><summary><b>Dá ban nos jogos com anti-cheat?</b></summary><br>Não injeta nada nos jogos: o overlay é uma janela por cima e o FPS é lido pelos eventos do Windows. Se um anti-cheat não gostar do driver dos sensores, a app passa sozinha ao Safe Mode.</details>
<details><summary><b>Os meus dados vão para algum lado?</b></summary><br>Não. Fica tudo no PC. As estatísticas anónimas só são enviadas se disseres que sim, e dá para desligar e apagar. Ver <a href="PRIVACY.md">PRIVACY.md</a>.</details>
